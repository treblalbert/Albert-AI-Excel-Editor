PUT YOUR icon.ico FILE HERE

The icon must be a proper .ico file (not a renamed .png).

To create one:
1. Start with a 256x256 PNG image
2. Go to https://convertio.co/png-ico/ or https://icoconvert.com/
3. Convert and download the .ico file
4. Save it here as "icon.ico"

Without a proper icon.ico, the build will fail or use default Electron icon.
