Help & Keyboard Shortcuts

⌨️ Keyboard Shortcuts

Ctrl+ZUndo last action
Ctrl+CCopy selected cells
Ctrl+XCut selected cells
Ctrl+VPaste cells
Ctrl+ASelect all cells
Ctrl+FFind/Search
Ctrl+HFind & Replace
DeleteClear selected cells
EnterEdit cell / Move down
TabMove to next cell
EscCancel / Close dialogs
Arrow KeysNavigate cells

🖱️ Mouse Actions

Click: Select a cell
Click + Drag: Select multiple cells
Shift + Click: Extend selection
Double Click: Edit cell content
Drag Fill Handle: Auto-fill cells (bottom-right corner square)
Drag Column Border: Resize column width

✨ Features

Column Filters: Click ▼ on headers to filter by values, text, or numbers
AI Assistant: Ask questions or request modifications in natural language
Compare Changes: View before/after comparison of your data
Highlight Changes: Toggle to see AI-modified cells
Export Formats: Download as .xlsx, .xls, or .csv

💡 AI Tips

• Ask questions: "What's the sum of column B?" or "How many rows have sales > 1000?"

• Request modifications: "Add 10% to all prices" or "Convert names to uppercase"

• Add data: "Add a new column called 'Total' with the sum of columns B and C"

• For large datasets (100+ rows), processing is done in batches automatically
